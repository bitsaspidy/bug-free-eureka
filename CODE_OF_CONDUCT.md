# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Read that text for the full standard. This file only adds the project-specific contact details.

## Scope

It applies in project spaces (issues, pull requests, discussions, reviews, and project chat) and when you represent the project in public.

## Enforcement contact

Report unacceptable behavior privately through GitHub: open a private security advisory on the repository (see [SECURITY.md](SECURITY.md) for the link), or send a private message to the owner, [@bitsaspidy](https://github.com/bitsaspidy). Do not post reports in public issues or pull requests.

The owner reviews each report and decides the response, following the Contributor Covenant enforcement guidelines. Reports are handled in confidence. There is no response-time guarantee.
