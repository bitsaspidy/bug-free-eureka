# Security Policy

## Supported versions

No release has been published yet. Only the `main` branch is maintained.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:

**[Report a vulnerability](https://github.com/bitsaspidy/bug-free-eureka/security/advisories/new)** (GitHub private vulnerability reporting)

Do not open a public issue, pull request or discussion for a suspected vulnerability.

Include, if you can:

- the affected package, version or commit;
- steps to reproduce, or a minimal fixture;
- the impact you expect.

Do not include real secrets, tokens or customer data. Redact them.

## What to expect

- The owner, Devavrat Singh ([@bitsaspidy](https://github.com/bitsaspidy)), reviews reports.
- Replies are best effort. This project does not offer a response-time SLA or a guaranteed fix date.
- Fixes are developed in private advisories and released with a disclosure note when ready.

## Scope and claims

Bug-Free Eureka helps find configuration issues. It does not guarantee that an app is secure. A clean report does not mean the app has no vulnerabilities.
